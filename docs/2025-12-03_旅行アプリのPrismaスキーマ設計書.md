## 🗂️ 概要

このドキュメントは、Prisma を用いて設計された旅行アプリケーションのデータベーススキーマの概要を示すものです。ユーザー、旅行、場所、写真、レビュー、通知、セッションなどの主要なデータ構造とそのリレーションを含みます。

---

## 📦 モデル一覧

### 🧑‍💼 User

| フィールド名        | 型       | オプション                        | 説明 |
|---------------------|----------|----------------------------------|------|
| id                  | String   | @id, @default(uuid())            | 主キー |
| email               | String   | @unique                          | ユーザーのメールアドレス |
| password            | String?  |                                  | パスワード（オプション） |
| name                | String?  |                                  | 名前（オプション） |
| image               | String?  |                                  | プロフィール画像（オプション） |
| emailVerified       | DateTime?| @map("email_verified")           | メール確認日 |
| createdAt           | DateTime | @default(now()), @map("created_at") | 作成日 |
| updatedAt           | DateTime | @updatedAt, @map("updated_at")   | 更新日 |

関連モデル: Account[], Session[], Trip[], Place[], Photo[], Review[], TripMember[], Friendship[], Notification[]
